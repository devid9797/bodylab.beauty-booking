# Новый дизайн (прототип)

Прототип нового визуального стиля на трёх языках (LV / RU / EN). **Не заменяет** текущий сайт: всё лежит в `/new/`,
закрыто от поисковиков (`noindex`) и не входит в sitemap. Палитра – та же, что у основного сайта.

| Страница | Адрес |
|---|---|
| Главная | `/new/lv/`, `/new/ru/`, `/new/en/` |
| Запись (демо, без отправки) | блок `#zapis` на главной, сразу после первого экрана |
| Подбор процедуры (тест из 10 вопросов) | блок `#podbor` на главной |
| Страницы процедур | `/new/<язык>/<slug>/` (`r-sleek`, `b-flexy`, `ems-zero`, `presoterapija`; на английском `pressotherapy`) |

## Как это собрано

Все HTML-страницы **генерируются** – руками их не правим:

    node new/build.mjs

- `new/build.mjs` – шаблоны страниц
- `new/i18n.mjs` – тексты на трёх языках (где на основном сайте уже есть формулировка, она взята оттуда)
- `new/quiz.mjs` – вопросы теста и баллы (привязаны только к опубликованным целям процедур)
- список фото студии – `STUDIO` в `new/build.mjs` (сюда добавляются новые фото)
- цены, описания и FAQ процедур – из `tools/content.mjs` (общий источник с основным сайтом)
- `new/assets/new.css`, `new.js` (общие, в т.ч. лайтбокс для фото), `home.js` (главная), `booking.js` (запись), `quiz.js` (тест)

Пути относительные, поэтому страницы открываются и с сервера, и двойным кликом из папки
(нужен интернет – шрифт Montserrat грузится с Google Fonts).
Предпросмотр с сервера: `python3 -m http.server`, затем `/new/ru/`.

## Что важно знать

- Страница записи – **только интерфейс**: доступное время сгенерировано, форма ничего не отправляет.
  Реальный календарь и отправка остаются на текущих страницах.
- Латышские тексты новых блоков написаны для прототипа – их стоит показать носителю языка.
