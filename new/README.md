# Новый дизайн (прототип)

Прототип нового визуального стиля. **Не заменяет** текущий сайт: всё лежит в `/new/`,
закрыто от поисковиков (`noindex`) и не входит в sitemap. Палитра – та же, что у основного сайта.

| Страница | Файл |
|---|---|
| Главная | `new/ru/index.html` |
| Запись (демо, без отправки) | `new/ru/zapis/index.html` + `new/assets/booking.js` |
| Страницы процедур | `new/ru/<slug>/index.html` – **генерируются** |

Страницы процедур собираются из `tools/content.mjs` (цены, тексты, FAQ – один источник с основным сайтом):

    node new/build.mjs

Общие файлы: `new/assets/new.css` (стили), `new/assets/new.js` (общие скрипты),
`new/assets/home.js` (только главная). Предпросмотр: можно просто открыть `new/ru/index.html` двойным кликом (пути относительные) или запустить `python3 -m http.server` и зайти на `/new/ru/`. Нужен интернет – шрифт Montserrat грузится с Google Fonts.

Страница записи – только интерфейс: доступное время сгенерировано, форма ничего не отправляет.
Реальный календарь и отправка остаются на текущей странице `/ru/`.
